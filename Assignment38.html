Q38 Viva - auto-fill vs auto-fit:
auto-fill = khali tracks bhi bana deta hai (grid lines reserve), auto-fit = khali jagah ko collapse karke items ko stretch kar deta hai. Dono se reflow hota hai bina media query ke. Resize karke dekho - automatically columns 4 se 3 se 2 se 1 ho jayenge. Ye pure CSS Grid ka power hai, Flex-wrap se better 2D control!
