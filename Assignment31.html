Q31 - Explanation (For Viva)

display:flex ka use:

  • .navbar { display: flex; justify-content: space-between; align-items: center; } → Logo aur Menu ko ek line me left-right karta hai.
  • .menu { display: flex; gap: 20px; } → Menu items ko horizontal line me lata hai bina float ke.
  • flex-wrap: wrap → Mobile pe wrap hone deta hai, overflow nahi hota (Q28 fix).
  • flex-direction: column in media query → Mobile pe menu vertical ban jata hai.

Responsive Logic: Desktop pe flex row, Mobile pe hamburger button se menu toggle + flex column. No JavaScript framework, only 1 line JS for toggle.

Test: Screen chhoti karo (Ctrl+Shift+I → mobile icon) toh menu hamburger me badal jayega.
