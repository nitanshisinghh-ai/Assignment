Q36 Viva Points:
  • display: grid; - Container ko grid banata hai
  • grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); - Auto responsive: screen ke hisab se columns banenge, har column min 250px
  • gap: 15px; - Items ke beech space
  • grid-column: span 2; - Kisi item ko 2 column ka width dena
  • Flex vs Grid: Flex 1D (row/col), Grid 2D (row+col both) - Gallery ke liye Grid best hai
