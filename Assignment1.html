Q1-Write a one-paragraph explanation of what happens between typing a URL and seeing the page.

When you type a URL in the browser and press Enter, the browser first checks its cache and then asks the DNS server to convert the domain name into an IP address. After getting the IP address, the browser sends an HTTP request to the web server using TCP/IP connection. The server processes the request and sends back the HTML, CSS, and JavaScript files as a response. Finally, the browser parses and renders these files to display the complete webpage on your screen.
