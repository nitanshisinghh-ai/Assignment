Design Token System

Q24 - Using CSS Variables (Custom Properties) for Colours, Font Sizes, Spacing

:root { --color-primary: #1A237E; --text-base: 16px; }

1. Colour Tokens

--color-primary #1A237E
--color-secondary #283593
--color-accent #FFC107
--color-text-light #757575

If we change in :root, whole site changes!

2. Font Size Tokens

--text-xs: 12px - Extra Small

--text-sm: 14px - Small

--text-base: 16px - Base

--text-lg: 18px - Large

--text-xl: 24px - XL Heading

--text-2xl: 32px

3. How It Works

Before Q24: Har jagah direct color likhte the - color: #1A237E;

After Q24 (Tokens): Ek jagah variable define - var(--color-primary)

Benefit: Client bole "blue thoda light karo" to sirf :root me 1 line change, poori site update!

4. Spacing & Radius Tokens

Spacing: --space-sm: 8px, --space-md: 16px, --space-lg: 24px

--radius-sm --radius-md --radius-lg
